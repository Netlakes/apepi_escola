# Referência Canônica do Tema
A pasta `apepi-escolao/` é a referência oficial e canônica para todos os arquivos atualizados do tema WordPress APEPI Escola.
Sempre que fizer alterações ou consultar o tema, tenha como referência a pasta `apepi-escolao/`.
Ao gerar novos arquivos empacotados ou atualizar espelhos (`temas/apepi-escola` ou `temawp/apepi-escola`), mantenha-os sempre sincronizados com `apepi-escolao/`.
